## 已确认配置

- A整机CAD为当前最新版本。
- V构形对应上反角。
- 变构采用单舵机、双层反向绕线与柔性回弹设计。
- 舵机为南古NANGU 20KG碳刷款。
- 四台电机为EMAX ECO II 2807 1300KV，独立桨模型为HQ DP7X4X3 CW/CCW。

## 建模参数

| 项目 | 工作内容 |
|---|---|
| 坐标与旋翼 | 提取位置，统一机体系、编号、轴向及旋向 |
| 关节 | 划分运动部件，建立等效弯曲自由度、滑动范围和限位 |
| 传动 | 建立舵机输入到H/V关节目标的映射 |
| 柔性 | 集中设置刚度、阻尼及回复参数 |
| 质量属性 | 按运动分组重算重心和惯量，补充设备位置及质量 |
| 动力 | 补充电池配置、舵机规格及电机桨性能数据 |
| 验证 | 地面指令变构、固定H/V飞行、空中连续变构分阶段实施 |

首版使用可替换的近似参数推进。当前质量与动力假设见[参数接入记录](../candidate_flight/handoff_audit/report.md)，任务顺序见[实施计划](../../docs/OpenCode后续执行计划.md)。
