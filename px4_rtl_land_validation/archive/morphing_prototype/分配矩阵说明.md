# 推力效能矩阵

本工具根据旋翼位置、推力轴和反扭矩比生成效能矩阵，用于参考台架与后续A模型的分构形计算。

## 通用关系

采用FRD机体系：X向前、Y向右、Z向下。给定构形q、相对参考点的旋翼位置r_i(q)（m）、推力方向单位向量d_i(q)、有符号反扭矩比k_i（m），单桨实际推力T_i（N）对应：

```text
B_i(q) = [ r_i(q) × d_i(q) - k_i d_i(q) ]
         [             d_i(q)          ]

[tau_x, tau_y, tau_z, F_x, F_y, F_z]^T = B(q) T
```

参考点通常取当前整机重心。推力竖直向上时，`d_i=(0,0,-1)`，可简化为：

```text
B_i = [-y_i, x_i, k_i, 0, 0, -1]^T
```

PX4 v1.17的`ActuatorEffectivenessRotors::computeEffectivenessMatrix`按CT_i缩放矩阵列，`module.yaml`采用`T_i=CT_i*u_i²`。KM包含旋向符号。对接时分别处理物理推力模型和归一化执行器映射。

## 参考台架配置

| 参数 | 示例设置 |
|---|---|
| 几何 | UAV.STEP |
| 关节中心 | FRD (±45,±45,0) mm |
| H/V端点 | 25° |
| 反扭矩比 | ±0.01m |
| 输入 | q∈[-1,1]，0为X，正值H，负值V |
| 切换 | 经X中立态转换 |

台架采用镜像同角运动。A模型使用其自身几何、质量和传动配置。

## 核对内容

`kinematics.py`检查中立态、竖直特例、单位轴向、向量求和与矩阵乘积一致性，以及V构形高度方向。示例X/H/V矩阵秩均为4，对应四个独立推力输入。

效能矩阵描述旋翼推力产生的合力和力矩。重心/惯量变化、机臂运动惯性、弹性及绳索力由动力学模型处理；推力上下限和执行器约束由分配器处理。

## 输出

- `allocation_demo.json`：三态矩阵、输入及核对结果。
- `bench_assumptions.json`：台架配置。
- `verification_X/H/V.json`：Gazebo位姿与解析几何比较。
- `cad_inspection.json`：参考STEP实体及几何信息。
