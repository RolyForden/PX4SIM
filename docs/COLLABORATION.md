# 协作与交接说明

本仓库用于共享通用代码、接口约定和经过证据支持的进度。原始技术资料与设计细节暂不公开，也不在此自动附加开源许可证；团队成果的许可范围需要另行确认。

## 当前分工与交付

当前负责内容为 Gazebo 模型和不同构形的推力/力矩分配矩阵。近期可以录制演示视频，但演示是否必须包含PX4闭环飞行、允许采用什么模型近似，仍需确认。

视频应区分以下证据等级：

1. 仅几何或关节动作展示：模型能按指令改变姿态或形状。
2. 动力学检查：关节、质量、惯量和执行器的运动行为已经核对。
3. 飞控闭环验证：PX4读取仿真传感器并控制执行器，具有真实状态和日志记录。

第一项完成不能写成第三项完成。只有日志、命令输出、截图或实际文件等证据支持的内容，才能标为已验证。

## 模型与参数交接

内部交接时，应记录文件版本、来源、单位、坐标系和可共享范围。关键输入包括：

- 关节位置、轴向、自由度、限位，以及主动或被动运动方式。
- 关节刚度、阻尼、摩擦与驱动特性，注明测量、CAD计算或估计来源。
- 构形定义及转换过程，旋翼位置、推力轴和重心随构形的变化关系。
- 旋翼编号、旋转方向、推力曲线和反扭矩系数。
- 质量、惯量、传感器安装与控制器分工。

未知项保持待定。CAD几何不能自动提供以上全部动力学参数。

## 代码协作

- 标准X500保留为基线，自研模型使用独立目录和机型配置。
- 使用功能分支提交改动，通过PR说明改了什么、如何验证、还有什么限制。
- 首次提交或修改共享范围时，检查 `git diff --cached --name-only`；不要强行加入被忽略的文件。
- 不提交PX4源码副本、Python虚拟环境、容器导出文件、账号信息或本机屏幕全景。
- 公开设计图、具体模型和内部文档前，另行确认团队授权；加入协作者本身不会让公开仓库变为私有。

## 运行与验证

现有脚本使用pymavlink，不依赖MAVROS。Gazebo Classic插件与Harmonic插件不能仅通过修改路径互换；历史模型需逐项核对平台和接口。

运行前确认本机仿真进程、模型、专用回环端口与参数快照。未明确安排的阶段不启动解锁或飞行测试，不连接真实飞控。任何需要修改PX4源码或系统依赖的工作，应先说明范围、依据和回滚方法。

本地详细交接与资料阅读记录单独保留；公开文档只包含经过共享范围检查的内容。
