# 标准四旋翼验证记录

[返回项目首页](../README.md)

测试日期：2026-11-12。使用 PX4 v1.17.0、Gazebo Harmonic 8.15.0、官方 X500 和默认平地场景。没有导入自研机型，没有修改控制算法或 PID。

| 工况 | 关键操作 | 观察结果 |
|---|---|---|
| 自动返航（Return） | 约10米起飞悬停，向北飞离约40米，切换返航模式 | 爬升至约30米，返回起飞点附近，下降、接地、自动上锁 |
| 自动降落（Land） | 从约10米稳定悬停直接进入降落模式 | 自动下降、接地、自动上锁 |
| 单参数对照 | 只将 `MPC_LAND_SPEED` 从0.7改为1.0 m/s | 低空下降速度增加，完成落地与自动上锁，之后恢复0.7 |

| 指标 | 自动返航 | 自动降落 | 降落速度对照 |
|---|---:|---:|---:|
| 最大相对高度 m | 29.97 | 9.98 | 9.98 |
| 离地1–4米下降速度中位数 m/s | 0.694 | 0.699 | 1.018 |
| 模式进入至接地 s | 46.972 | 13.784 | 10.808 |
| 接地至自动上锁 s | 2.012 | 2.008 | 2.008 |

Return的耗时包含爬升与水平返航，不能直接与Land作为下降速度对比。每种工况只有一次，尚未构成可靠性统计。低空速度统计采用NED垂直速度，向下为正。

原始参数为 `RTL_TYPE=0`、`RTL_RETURN_ALT=30 m`、`RTL_DESCEND_ALT=10 m`、`RTL_LAND_DELAY=0 s`、`MPC_LAND_SPEED=0.7 m/s`、`COM_DISARM_LAND=2 s`。这些是本次运行值，不是对实机的调参建议。

本地保留 `rtl_default.ulg`、`land_default.ulg`、`land_speed_1p0.ulg` 三份原生日志，副本与原件的SHA256已经核对；原始数据在 [Release 附件](https://github.com/RolyForden/PX4SIM/releases/tag/validation-2026-11-14) 中下载。分析曲线、数值汇总与测试前后参数快照在仓库对应目录提供。

## 结论边界

本次结果支持“当前软件与标准X500场景下，基本返航和降落闭环可执行”。它不证明自研机型的质量、惯量、关节动力学、构形切换或控制分配正确，也不解释此前实机事故。

目前没有根据这些单次测试调整默认PID或实机降落速度的依据。后续模型必须单独验证，标准X500作为回归基线保留。
