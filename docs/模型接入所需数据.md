# 模型接入与后续资料

[返回首页](../README.md)

自研A整机CAD、BOM和近似质量参数已经接入，固定构形飞行已通过。当前工作转向A模型关节、ROS指令和不同构形推力分配，不必等待所有参数精确。

已有交底书及附图足以启动近似变构建模。向师姐主要确认**当前实现与现有设计是否有改动，以及是否有未交接的原始装配/动作视频/控制工程**。CAD可提取的尺寸与坐标由我们处理，不将内部建模问题都变成资料要求。

具体材料审阅及内部缺失项见[本地材料整理](../px4_rtl_land_validation/现实材料/模型资料交接清单.md)，执行步骤见[后续计划](OpenCode后续执行计划.md)。未知角度、柔性和动力参数集中记录为可替换假设；没有现成数据不要求新增实物测试。
