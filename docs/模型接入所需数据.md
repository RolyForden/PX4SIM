# 最终样机接入所需数据

[返回首页](../README.md)

当前 STEP 只作参考。最终样机仿真需要以下输入，未知项保留待定，不能用参考模型数值直接替代。

| 数据 | 用途 |
|---|---|
| 最终 CAD、版本、单位与坐标系 | 确认真实几何与安装关系 |
| 关节轴、位置、自由度、限位及构形范围 | 建立实际机构运动 |
| 主动/被动关节、驱动与传动关系 | 从控制指令得到关节运动 |
| 刚度、阻尼、摩擦、驱动响应 | 验证柔性关节动力学 |
| 各部件质量、重心、惯量 | 建立动力学和构形变化模型 |
| 旋翼编号、位置、推力轴、旋向 | 计算推力效能矩阵及执行器映射 |
| 推力曲线与反扭矩系数 | 将执行器输出映射为力和力矩 |
| 实机 PX4 版本与现有自定义代码 | 确定仿真与控制接口 |

工作顺序：最终几何核对 → 机构与动力学检查 → 矩阵与执行器映射 → PX4 接入 → 分阶段飞行验证。CAD 不能自动提供全部动力学参数。
