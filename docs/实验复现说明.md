## 环境

| 组件 | 版本或配置 |
|---|---|
| Ubuntu | 22.04 |
| PX4 | v1.17.0，`d6f12ad1c4f70ad3230afd7d86e971421e02fef4` |
| Gazebo | Harmonic 8.15.0 |
| 标准机型 | gz_x500，SYS_AUTOSTART=4001 |
| QGroundControl | v5.0.8 |
| 容器 | px4-rtl-land-harmonic |
| MAVLink | 127.0.0.1:14650/14651 |

运行需准备上述容器、PX4源码和编译产物，以及根目录`requirements.txt`中的Python依赖。脚本采用本机目录与容器布局。

## 标准X500测试

加载X500后，分别执行以下仿真飞行测试。脚本会核对本机PX4进程、心跳和机型编号。

```sh
python px4_rtl_land_validation/validate.py rtl --name rtl_default
python px4_rtl_land_validation/validate.py land --name land_default
```

测试生成`logs/`和`parameters/`。复测时使用新的`--name`归档。

## 日志分析

从[标准测试Release](https://github.com/RolyForden/PX4SIM/releases/tag/validation-2026-11-14)下载ULog至`px4_rtl_land_validation/logs/`，运行：

```sh
python px4_rtl_land_validation/analyze.py
```

曲线和汇总输出到`analysis/`。
