## 自动飞行测试

先确认运行的是本机仿真、标准X500已经加载且没有连接真实飞控。控制端口为 `127.0.0.1:14650/14651`，容器名为 `px4-rtl-land-harmonic`。脚本会核对本机PX4进程、PX4心跳和机型编号。

`validate.py` 会实际发送解锁、起飞和模式切换指令，只有明确安排测试后才运行：

```sh
# 自动返航测试
python px4_rtl_land_validation/validate.py rtl --name rtl_default

# 自动降落测试
python px4_rtl_land_validation/validate.py land --name land_default
```

将两次测试分开执行并检查结果，先保存已有同名输出。脚本会在本地生成 `logs/` 和 `parameters/`，目录不会提交到公开仓库。

## 原始日志分析

将真实 `.ulg` 文件放入本地 `px4_rtl_land_validation/logs/` 后运行：

```sh
python px4_rtl_land_validation/analyze.py
```

生成的图和汇总保存在本地 `analysis/`。分析脚本不会生成虚构的飞行数据；未取得原始日志时不能用空白输出代替实验结果。
