# 仓库阅读指南

[返回项目首页](../README.md)

这个仓库可以当作团队的在线项目资料夹。查看进度和实验结论不需要安装 Git、下载代码或启动仿真。

## 只看进度与结果

打开[项目首页](https://github.com/RolyForden/PX4SIM)，向下滚动即可看到中文说明，不必先点击顶部的代码文件。首页依次列出阅读入口、项目进度、已完成实验和下一步工作。

需要核对实验时，点击[标准四旋翼验证记录](标准四旋翼验证.md)。需要确认交接内容时，点击[协作与资料交接](协作与资料交接.md)。每篇文档顶部均有返回首页的链接。

页面会直接显示文档正文；`.md` 是 Markdown 文本文件的后缀，不需要额外软件。

## 留言或提出问题

1. 登录自己的 GitHub 账号，打开[问题讨论区](https://github.com/RolyForden/PX4SIM/issues)。
2. 点击 **New issue（新建问题）**，选择“团队反馈”，填写中文标题和内容。
3. 按页面提示提交。已有同一话题时，点开对应条目，在下方直接回复即可。

这里只创建了反馈模板，尚未代任何人发送消息或分配任务。内容可以写“模型导出格式需要确认”“某次实验结论需要补充依据”等普通进度问题。

**仓库和讨论区目前均公开。**不要在正文、评论或附件中上传技术交底书、CAD、具体设计参数、原始日志、密码或访问令牌。需要讨论内部设计时，使用团队约定的内部渠道。

## 常见英文按钮对照

| 页面文字 | 可以理解为 | 是否需要用 |
|---|---|---|
| Code | 项目文件和首页 | 日常阅读主要看这里 |
| Issues | 问题讨论与反馈 | 需要留言时使用 |
| New issue | 新建一条问题 | 发起新话题时使用 |
| Pull requests | 代码或文档修改申请 | 修改仓库内容的成员使用 |
| Commits | 历次提交记录 | 想看什么时候改了什么时使用 |
| Public | 公开仓库 | 表示任何人都可能看到内容 |
| Settings | 仓库设置 | 仓库管理者使用 |
| Star / Fork | 收藏关注 / 复制一份仓库 | 普通阅读不需要操作 |

GitHub网站自身的导航可能仍显示英文；项目首页、文档、反馈模板和后续进度说明优先使用中文。软件名、参数名和程序文件名保留原文，方便核对和运行。

## 哪些资料不在这里

公开仓库只收录经过共享范围检查的内容。原始CAD、内部技术说明、STAR-CCM+工程、原始日志及未公开设计细节先留在本地。找不到这些文件并不表示资料丢失或项目没有对应资产。

需要复查原始数据时，请联系项目负责成员，通过内部渠道获取。需要在自己的电脑上运行仿真，再阅读[实验复现说明](实验复现说明.md)；仅下载仓库不能直接启动完整环境。

参考：[GitHub仓库与首页说明](https://docs.github.com/en/repositories/creating-and-managing-repositories/quickstart-for-repositories)、[新建问题的官方说明](https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/creating-an-issue)。
